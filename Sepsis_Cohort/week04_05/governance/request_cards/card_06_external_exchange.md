# Request 6: External Exchange

A competing health system requests the patient's transfer summary, medication administrations, laboratory trends, and culture results for a subsequent treatment encounter.

The technical connection is available, but a local leader proposes delaying the exchange because easier access might encourage patients to obtain follow-up care elsewhere.

## Added detail

The privacy office has not identified a patient-specific privacy or security concern, but staff are uncertain whether every requested element is needed.

## Discuss

- Which clinical purpose does the request serve?
- How should legitimate privacy or security concerns be distinguished from organizational preference?
- What could happen to the patient if appropriate information is withheld?
