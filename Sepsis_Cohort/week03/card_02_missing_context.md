# Complication Card 2

## A Value Without Enough Context

The receiving system displays a new lactate result:

```text
Lactate: 4.2
```

The display does not include a unit, specimen collection time, result time, reference range, source organization, or indication of whether this is the initial or repeat result.

### Discuss

1. Can the clinician understand the result confidently?
2. Can the computer compare it with the previous result safely?
3. Which missing elements are necessary for interpretation?
4. What does this demonstrate about transmitting a value versus transmitting usable information?
